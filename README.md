# PDF

## Project Overview

A complete PDF processing toolkit with 16 specialized tools. Handle everything from basic operations like merging and splitting to advanced features like encryption, watermarking, and format conversion.

## Block Capabilities

### Core Operations
- **PDF Merge** - Combine multiple PDFs into one document
- **PDF Split** - Divide PDFs by pages, ranges, or bookmarks
- **PDF Rotate** - Fix page orientation (90°, 180°, 270°)
- **PDF Delete Pages** - Remove unwanted pages

### Security & Protection
- **PDF Encrypt** - Password protect with permission controls
- **PDF Decrypt** - Remove password protection

### Content Enhancement
- **PDF Watermark** - Add text or image watermarks
- **PDF Annotate** - Add notes, highlights, and stamps

### Format Conversion
- **HTML to PDF** - Convert HTML content to PDF
- **Markdown to PDF** - Convert Markdown to styled PDF
- **Text to PDF** - Convert plain text to formatted PDF
- **PDF to Images** - Convert PDF pages to image files
- **Images to PDF** - Combine images into a PDF

### Information Extraction
- **PDF Text Extract** - Pull text content from PDFs
- **PDF Metadata** - Extract document information

## Block Combination Suggestions

**Document Preparation**: Text/HTML/Markdown to PDF → Merge → Watermark
**Security Workflow**: Watermark → Encrypt → Metadata
**Content Extraction**: Split → Text Extract → PDF to Images
**Document Cleanup**: Rotate → Delete Pages → Compress

## Basic Usage

1. Select a block from the toolkit
2. Provide the required input (PDF file, text, or images)
3. Configure optional settings (output path, styling, permissions)
4. Run the block to process your document

## Examples

**Merge reports**: Use PDF Merge with multiple PDF files → single combined document
**Protect contract**: Use PDF Encrypt with user password → secure document
**Convert notes**: Use Markdown to PDF with your content → styled PDF
**Extract text**: Use PDF Text Extract with any PDF → editable text content
