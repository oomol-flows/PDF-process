# PDF

## 项目概述

一个完整的 PDF 处理工具箱，包含 16 个专业工具。从合并、拆分等基本操作到加密、水印、格式转换等高级功能，一站式解决所有 PDF 处理需求。

## 功能模块

### 核心操作
- **PDF 合并** - 将多个 PDF 合并为一个文档
- **PDF 拆分** - 按页面、范围或书签分割 PDF
- **PDF 旋转** - 修正页面方向（90°、180°、270°）
- **PDF 删除页面** - 移除不需要的页面

### 安全保护
- **PDF 加密** - 密码保护并控制权限
- **PDF 解密** - 移除密码保护

### 内容增强
- **PDF 水印** - 添加文字或图片水印
- **PDF 注释** - 添加备注、高亮和印章

### 格式转换
- **HTML 转 PDF** - 将 HTML 内容转换为 PDF
- **Markdown 转 PDF** - 将 Markdown 转换为精美 PDF
- **文本转 PDF** - 将纯文本转换为格式化 PDF
- **PDF 转图片** - 将 PDF 页面转换为图片文件
- **图片转 PDF** - 将多张图片合并为 PDF

### 信息提取
- **PDF 文字提取** - 从 PDF 中提取文字内容
- **PDF 元数据** - 提取文档信息

> **注意**：如果您的 PDF 全是图片无法提取文字，请使用 `pdf-craft-cloud` 包。它通过云端 OCR 服务将图片型 PDF 转换为 Markdown 格式，保留原有排版和格式。

## 组合建议

**文档准备**：文本/HTML/Markdown 转 PDF → 合并 → 水印
**安全流程**：水印 → 加密 → 元数据
**内容提取**：拆分 → 文字提取 → PDF 转图片
**文档清理**：旋转 → 删除页面 → 压缩

## 基本用法

1. 从工具箱中选择一个功能模块
2. 提供所需的输入（PDF 文件、文本或图片）
3. 配置可选设置（输出路径、样式、权限等）
4. 运行模块处理文档

## 使用示例

**合并报告**：使用 PDF 合并，输入多个 PDF 文件 → 生成一份完整文档
**保护合同**：使用 PDF 加密，设置用户密码 → 生成安全文档
**转换笔记**：使用 Markdown 转 PDF，输入内容 → 生成精美 PDF
**提取文字**：使用 PDF 文字提取，输入任意 PDF → 获取可编辑文字
