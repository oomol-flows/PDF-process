# PDF 处理工具箱

一个完整的 PDF 处理工具箱，帮助你轻松处理各种 PDF 文档任务。无论是合并多个文件、添加水印、提取文字，还是转换格式，这个工具箱都提供简单直观的解决方案。

## ✨ 这个工具箱能做什么？

这个工具箱将你的工作空间变成一个 PDF 处理中心。拥有 16 个专业工具，你可以处理从合并、拆分等基本操作到水印、加密、格式转换等高级功能的所有任务。

**主要功能：**
- 📄 **文档整理** - 轻松合并、拆分和重新排列页面
- 🎨 **内容增强** - 添加水印、注释和专业样式
- 🔒 **安全保护** - 密码保护和控制文档访问权限
- 🔄 **格式转换** - 在 PDF、图片、HTML 等格式之间转换
- 📊 **信息提取** - 从文档中提取文字和元数据

## 📦 可用工具

### 🔧 核心文档操作

#### **PDF 水印**
为文档添加专业水印，保护版权或标记品牌。
- 添加文字或图片水印
- 控制位置、透明度和旋转角度
- 在多个文档上应用一致的品牌标识

#### **PDF 压缩**
减小文件大小，便于分享和存储，同时保持质量。
- 根据需求选择压缩级别
- 查看压缩前后文件大小对比
- 在节省空间的同时保持文档可读性

#### **PDF 合并**
将多个 PDF 文件合并为一个文档。
- 合并报告、合同或演示文稿
- 保持原始页面顺序和书签
- 自动添加页码

#### **PDF 拆分**
将大型 PDF 分割成更小、更易管理的文件。
- 按页面范围拆分（如第 1-5 页、第 6-10 页）
- 在书签位置拆分
- 创建大小相等的文档

#### **PDF 转图片**
将 PDF 页面转换为图片文件。
- 选择图片格式（PNG、JPEG）
- 调整质量和分辨率
- 提取特定页面或整个文档

#### **图片转 PDF**
将多张图片合并为一个 PDF。
- 支持 JPEG、PNG 等格式
- 控制页面大小和方向
- 制作相册或演示文档

#### **PDF 元数据提取**
查看文档信息，如标题、作者和创建日期。
- 查看隐藏的文档属性
- 提取创建和修改日期
- 用于文档组织和追踪

### 🔒 安全与保护

#### **PDF 加密**
为敏感文档添加密码保护。
- 设置打开密码（查看文档需要）
- 设置权限密码（编辑/打印需要）
- 控制谁能打印、复制或修改

#### **PDF 解密**
移除你拥有的文档的密码保护。
- 使用正确密码解锁文档
- 处理多个受保护文件
- 验证保护状态

### 🎨 内容增强

#### **PDF 旋转**
修复横向或倒置的页面。
- 旋转 90°、180° 或 270°
- 旋转特定页面或整个文档
- 轻松纠正扫描错误

#### **PDF 文字提取**
从 PDF 中提取文字内容，用于编辑或分析。
- 导出为纯文本、JSON 或 CSV
- 从特定页面提取
- 保持文字顺序和布局

#### **PDF 页面删除**
从文档中删除不需要的页面。
- 删除单个页面或页面范围
- 清理草稿版本
- 移除空白或错误页面

#### **PDF 注释**
为文档添加备注、高亮和印章。
- 添加文字备注和评论
- 高亮重要部分
- 添加自定义印章（如"已批准"、"机密"）

### 🔄 格式转换

#### **HTML 转 PDF**
将网页和 HTML 内容转换为 PDF。
- 转换 HTML 代码、文件或网页链接
- 保持样式和布局
- 创建适合打印的文档

#### **Markdown 转 PDF**
将 Markdown 格式文本转换为专业 PDF。
- 支持标题、列表和表格
- 从多种配色主题中选择
- 调整字体大小以提高可读性

#### **文本转 PDF**
将纯文本转换为格式化的 PDF 文档。
- 简单文本变专业文档
- 选择字体和配色方案
- 添加文档标题

## 🎯 实际应用场景

### **商务文档**
- **报告整合**：将不同部门的季度报告合并成一份完整的文档
- **合同准备**：为合同草稿添加水印，发送前加密保护
- **发票处理**：从发票中提取文字用于数据录入，压缩后存档

### **教育资料**
- **课程材料**：合并讲义幻灯片，将阅读材料拆分成章节，添加页码
- **研究工作**：从论文中提取文字用于引用，将笔记转换为 PDF 格式
- **作业收集**：合并学生提交的作业，添加反馈注释

### **个人项目**
- **相册制作**：将照片转换为 PDF，合并成相册，添加说明文字
- **文档归档**：压缩旧文档，提取元数据进行整理
- **网页内容**：将网页保存为 PDF 以便离线阅读

### **法律与合规**
- **文档安全**：加密敏感文件，添加机密水印
- **证据整理**：拆分大型案卷文件，添加注释说明
- **记录管理**：提取文档元数据用于追踪和审计

## 💡 推荐工具组合

以下是一些常用的工具组合工作流程：

### **文档准备流程**
1. **文本/HTML/Markdown 转 PDF** → 转换你的内容
2. **PDF 合并** → 合并多个部分
3. **PDF 水印** → 添加品牌标识
4. **PDF 压缩** → 优化文件大小

### **安全保护流程**
1. **PDF 水印** → 添加机密标识
2. **PDF 加密** → 密码保护
3. **PDF 元数据提取** → 记录安全设置

### **内容提取流程**
1. **PDF 拆分** → 分离相关部分
2. **PDF 文字提取** → 提取内容
3. **PDF 转图片** → 转换图表和图示

### **文档清理流程**
1. **PDF 旋转** → 修正页面方向
2. **PDF 页面删除** → 删除不需要的页面
3. **PDF 压缩** → 减小最终文件大小

### **格式转换流程**
1. **图片转 PDF** → 转换照片
2. **PDF 合并** → 与其他文档合并
3. **PDF 水印** → 添加专业效果
